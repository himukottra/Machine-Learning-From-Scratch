## 📖 About

This repository contains my personal implementations of Machine Learning algorithms from scratch.

The goal is **not** to achieve the highest accuracy with existing libraries, but to understand how every algorithm works internally.

Every algorithm includes:

- Mathematical intuition
- Step-by-step implementation
- Well-commented code
- Training examples
- Visualization
- Performance comparison with Scikit-Learn (when appropriate)

---

## 🎯 Learning Objectives

✔ Learn Machine Learning mathematically

✔ Understand optimization algorithms

✔ Implement everything manually

✔ Build intuition instead of memorizing APIs

✔ Prepare for Research, Kaggle and Interviews
